Facturas PDF.
Excel limpio.

Este fue un experimento para evaluar un servicio que convirtiera lotes de facturas en una tabla estructurada: proveedor, NIF, número, fecha, base imponible, IVA y total.

La investigación se cerró sin lanzar campañas, cobrar ni recibir documentos de clientes.

Qué estamos comprobando

Extracción útil

No solo convertir un PDF: separar los campos que después necesitas filtrar, revisar o importar.

Excepciones visibles

Marcar datos dudosos para revisión en lugar de ocultar errores detrás de una automatización.

Privacidad desde el inicio

Retención mínima, acceso limitado y borrado de documentos tras completar el procesamiento.

Cómo se planteó

Definir el problema

Medir cuántas facturas se procesan y cómo se hace hoy el trabajo.

Acotar el piloto

Acordar campos, excepciones y límites antes de recibir cualquier documento.

Comparar el resultado

Excel estructurado, incidencias señaladas y contraste con el proceso anterior.

Resultado de la validación

Keyword Planner mostró poco volumen en las búsquedas específicas y costes publicitarios altos. La hipótesis no se prioriza como negocio independiente. La página permanece como documentación transparente del proceso de investigación y como ejemplo técnico; no se aceptan pagos, facturas ni datos fiscales.
